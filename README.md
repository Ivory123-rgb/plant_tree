# plan_tree
PlanTree: From Planting to Pantry

PlanTree is a personalized gardening application that is designed to guide users through the plant growing process, it also guides the users for harvesting, storing, and using their own produce.PlanTree is intended to simplify the process for users so that it is easier for them to track, record, and manage their plants.

Planned Features

1.) Virtual garden for tracking plants
2.) Virtual pantry for harvested produce
3.) Plant-care information 
4.) Produce fresness estimate
5.) Recipe recommendation based on users plants
6.) Food-storage reccomendation
7.) Plant recommendation based on growing condition
